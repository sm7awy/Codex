# AI Agent Dashboard MVP (Prototype)

هذا المشروع نسخة أولية سريعة (Prototype) لعرض واجهة لوحة تحكم إدارة الـ AI Agents.

## التشغيل المحلي

```bash
cd web
python3 -m http.server 4173
```

ثم افتح:

- http://localhost:4173

## المحتوى الحالي

- لوحة KPI
- قائمة Agents وحالاتهم
- صندوق موافقات
- المحادثات النشطة
- Logs فورية

> ملاحظة: هذه نسخة واجهة أمامية أولية فقط لعرض النتائج بسرعة.
